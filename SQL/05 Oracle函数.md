### (1).转换函数
#### 转换日期函数 to_date(X,[c 2])

- 【功能】将字符串 X 转化为日期型
- 【参数】x 是目标字符,c 2 是格式参数

#### 转换字符函数
to_char（目标数值或日期，['格式']）
作用：是将目标数值或者日期按照格式转换成字符类型
返回 字符
1．将数值转换成字符
```select 123.45,to_char(123.45) from dual;```
如何区分数值和字符——数值是右对齐字符是左对齐
```select 123.45,'123.45' from dual;```
格式
0      当整数位无数字则强制显示成 0，当小数位无数字则以 0 补全
    当整数位精度不足则显示成###，当小数位精度不足则四舍五入
9      当整数位无数字则格式不生效当小数位无数字则以 0 补全
    当整数位精度不足则显示成###，当小数位精度不足则四舍五入
```
select 123.45,to_char(123.45,'000.00') from dual;
select123.45,to_char(123.45,'00000.00')from dual;
——当整数位无数字则强制显示成 0
select123.45,to_char(123.45,'00000.0000')from dual;
-—当小数位无数字则以 0 补全
select 123.45,to_char(123.45,'000.0'）from dual;
-当小数位精度不足则四舍五入
select 123.45,to_char(123.44999999999999,'000.0'）from dual;
select 123.45,to_char(123.45,'9999999999999999.9999'）from dual;
——当整数位无数字则格式不生效  格式占位
```
添加货币符号
L----本地货币
＄----美元
```
select to_char(123.45,'L000.0000 元'）from dual -----￥123.4500
select to_char(123.45,'000.0000L'）from dual---------123.4500￥
select to_char(123.45,'000.0L000'）from dual---------无效
select to_char(123.45,'000.0$000'）from dual--------- $123.4500
select to_char(123.45,'000.0000$'）from dual--------- $123.4500
```
添加千位符 1，000
```
select to_char(123456789.123456,'999,999,999.99999999')from dual
select to_char(123456789.123456,'999,999,999.99999999')from dual
```

### 转换字符函数 to_char(目标数值或日期，['格式']

- 【功能】 将目标数值或者日期，按照格式转换成字符类型
	- 将数值转换成字符
		- 0
			- 当整数位无数字则强制显示成 0
			- 当小数位无数字 则以 0 补全
			- 当整数位精度不足 则显示成###
			- 当小数位精度不足则四舍五入
		- 9
			- 当整数位无数字则格式不生效
			- 当小数位无数字 则以 0 补全
			- 当整数位精度不足 则显示成###
			- 当小数位精度不足则四舍五入
		- 添加货币符号
			- L-------本地货币
				- select  to_char(123.45,'L 000.0000 元') from dual
				- select  to_char(123.45,'000.0000 L') from dual
			- ..-------美元
				- select to_char(123.45,'000.0$000') from dual
				- select to_char(123.45,'000.0000$') from dual
				- select to_char(123.45,'$000.0000') from dual
		- 添加千位符 1，000
			- select to_char(123456789.123456,'999,999,999.99999999') from dual
			- select to_char(123456789.123456,'9,9,9,9,9,9,9,9,9.99999999') from dual
	- 将日期转换为字符
		- sysdate
			- 获取当前日期（系统日期）
				- select  sysdate from dual;
		- to_char(sysdate,'d') 本周第几天
		- to_char(sysdate,'dd') 本月第几天
		- to_char(sysdate,'ddd') 本年第几天
		- to_char(sysdate,'w') 本月第几周
		- to_char(sysdate,'ww') 本年第几周
		- to_char(sysdate,'mm') 本年第几月
		- to_char(sysdate,'q') 本年第几季度
		- to_char(sysdate,'yyyy') 年
		- to_char(sysdate,'month') 月
		- to_char(sysdate,'day') 周几
- 【返回】字符
## 字符型函数

### 连接函数 concat(字符 1,字符 2)

- 【作用】 是将 字符 1 和字符 2 拼接到一起，拼接到一起变成一个字符 ，相当于  ||
- 【返回】 字符
### 大小写转换函数

- 大写函数 upper(字符)
	- 作用：将 所有的字符 变成大写
	- 返回 字符
- 小写函数 lower(字符)
	- 作用 将 所有的字符 变成小写
	- 返回 字符
- 首字母大写函数 initcap(字符)
	- 作用： 将 首字母变成大写，将其余的变成小写
	- 返回   字符
### 获取位置函数 instr(目标字符,要查询的字符 S,[位置参数 n 1],[次数参数 n 2])---------空格也占位，位置可以为负，从后往前找，次数不能为负

- 作用 是从第 n 1 个位置 找到 n 2 次出现的字符 S ，返回 该字符 在整个字符串中的  位置
- 返回 数值
### 获取字符长度函数  length(字符)

- 作用 获取字符的 长度
- 返回 数值
### 左右删除函数

- 左删除函数   ltrim(目标字符,[要删除的内容])
	- 作用 删除字符转左侧的要删的内容
	- 参数二默认，删除左侧的空格
	- 返回 字符
- 右删除函数  rtrim(目标字符,删除的字符)
	- 作用 删除字符转右侧的要删的内容
	- 参数二默认，删除右侧的空格
	- 返回 字符
- 删除左右字符函数  trim( [要删除的字符  from] 目标字符  )
	- 作用 删除 目标字符左右两侧的内容
	- 默认删除左右的空格
	- 返回 字符
### 替换函数  replace(目标字符, 要替换的字符,替换成的字符) 

- 作用 ：将目标字符中 某这个字符或者某些字符 替换成想要的字符
- 返回 ：字符
- 细分主题 3
### 截取函数  substr(目标字符,位置参数 n 1,长度参数 L 1)

- 作用 ：是 从 第 n 1 个位置 截取出 l 1 个长度 [G]长度默认截取到最后，位置参数必须有，位置参数可以为负数 从后开始数，，截取永远都是 从左往右截取，长度不能为负数
- 返回   字符

### 取整函数

- 向上取整  ceil(数值)
	- 作用 返回 离数值 最近的较大的整数
	- 返回 数值
- 向下取整  floor(数值)
	- 作用 返回 离数值最近的 较小的整数

### power(x,y)

- 【功能】返回 x 的 y 次幂
- 【参数】x，y 数字型表达式
- 【返回】数字
### 取余数函数  mod(x,y)

- 【功能】返回 x 除以 y 的余数 [G]奇数➗️2 余 1   偶数➗️ 余 0 
- 【参数】x,y，数字型表达式
- 【返回】数字
### round(x[,y])

- 【功能】返回四舍五入后的值，y 默认，保留整数，y 可以是负数，整数部分四舍五入后用 0 代替
- 【返回】数字
### 截断函数  trunc(x,[y])

- 作用 ：直接截断 不需要四舍五入  -默认保留整数，精度可以是负数  整数部分四舍五入之后用 0 代替
- 返回   数值

### 月份加减函数  add_months(日期 , n )

- 作用 ：在原有的日期的基础上 加 n 个月
- 返回   日期
### 四舍五入后的期间第一天 round(d 1[,c 1])

- 【功能】：给出日期 d 1 按期间（参数 c 1）四舍五入后的期间的第一天日期（与数值四舍五入意思相近）
- 【参数】：d 1 日期型，c 1 为字符型（参数），c 1 默认为 j（即最近 0 点日期）
- 【参数表】：
c 1 对应的参数表：
最近 0 点日期：取消参数 c 1 或 j
最近的星期日：day 或 dy 或 d
最近月初日期：month 或 mon 或 mm 或 rm
最近季日期：q
最近年初日期：syear 或 year 或 yyyy 或 yyy 或 yy 或 y（多个 y 表示精度）
最近世纪初日期：cc 或 scc
- 【返回】：日期
### trunc(d 1[,c 1])

- 【功能】：返回日期 d 1 所在期间（参数 c 1）的第一天日期
- 【参数】：d 1 日期型，c 1 为字符型（参数），c 1 默认为 j（即当前日期）
- 【参数表】：
c 1 对应的参数表：
最近 0 点日期：取消参数 c 1 或 j
最近的星期日：day 或 dy 或 d（每周顺序：日，一，二，三，四，五，六）
最近月初日期：month 或 mon 或 mm 或 rm
最近季日期：q
最近年初日期：syear 或 year 或 yyyy 或 yyy 或 yy 或 y（多个 y 表示精度）
最近世纪初日期：cc 或 scc
