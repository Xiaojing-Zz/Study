# Oracle SQL 完整查询语法与函数速查手册
## 一、完整查询语句

```sql
SELECT 列名, 聚合函数()
  FROM 表名
 WHERE 行过滤条件          -- 分组前的过滤条件
 GROUP BY 分组字段         -- 分组内容
 HAVING 分组后过滤条件      -- 分组后过滤条件
 ORDER BY 排序字段;        -- 永远最后执行
```

**执行顺序：** `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY`

### 3.2 to_char — 转换字符函数

```sql
to_char(目标数值或日期, ['格式'])
```

| 项目 | 说明 |
|------|------|
| **功能** | 将目标数值或日期按照格式转换成字符类型 |
| **返回** | 字符 |

#### 1）将数值转换成字符

```sql
-- 区分数值和字符：数值右对齐，字符左对齐
SELECT 123.45, '123.45' FROM dual;
SELECT 123.45, TO_CHAR(123.45) FROM dual;
```

**格式占位符 `0` 的规则：**
- 整数位无数字 → 强制显示成 0
- 小数位无数字 → 以 0 补全
- 整数位精度不足 → 显示成 `###`     
- 小数位精度不足 → 四舍五入

```sql
SELECT 123.45, TO_CHAR(123.45, '000.00') FROM dual;        -- 123.45
SELECT 123.45, TO_CHAR(123.45, '00000.00') FROM dual;      -- 00123.45（整数无数字则补0）
SELECT 123.45, TO_CHAR(123.45, '00000.0000') FROM dual;    -- 00123.4500（小数无数字则补0）
SELECT 123.45, TO_CHAR(123.45, '000.0') FROM dual;         -- 123.5（四舍五入）
SELECT 123.45, TO_CHAR(123.44999999999999, '000.0') FROM dual; -- 123.4（四舍五入）
```

**格式占位符 `9` 的规则：**
- 整数位无数字 → 格式不生效（不显示）
- 小数位无数字 → 以 0 补全
- 整数位精度不足 → 显示成 `###`
- 小数位精度不足 → 四舍五入

```sql
SELECT 123.45, TO_CHAR(123.45, '9999999999999999.9999') FROM dual; -- 整数无数字则不生效，格式占位
```

**添加货币符号：**

| 符号 | 含义 | 示例 |
|------|------|------|
| `L` | 本地货币（￥） | `TO_CHAR(123.45, 'L000.0000元')` → `￥123.4500元` |
| `$` | 美元 | `TO_CHAR(123.45, '000.0$000')` → `$123.4500` |

```sql
SELECT TO_CHAR(123.45, 'L000.0000元') FROM dual;  -- ￥123.4500元
SELECT TO_CHAR(123.45, '000.0000L') FROM dual;     -- 123.4500￥（货币符号放最后也生效）
SELECT TO_CHAR(123.45, '$000.0000') FROM dual;     -- $123.4500
SELECT TO_CHAR(123.45, '000.0000$') FROM dual;     -- $123.4500（$放最后也生效）
```

**添加千位符：**

```sql
SELECT TO_CHAR(123456789.123456, '999,999,999.99999999') FROM dual;
-- 结果：123,456,789.12345600
```

#### 2）将日期转换为字符

```sql
-- 获取当前系统日期
SELECT SYSDATE FROM dual;
```

| 格式 | 含义 | 示例 |
|------|------|------|
| `d` | 本周第几天 | `TO_CHAR(SYSDATE, 'd')` |
| `dd` | 本月第几天 | `TO_CHAR(SYSDATE, 'dd')` |
| `ddd` | 本年第几天 | `TO_CHAR(SYSDATE, 'ddd')` |
| `w` | 本月第几周 | `TO_CHAR(SYSDATE, 'w')` |
| `ww` | 本年第几周 | `TO_CHAR(SYSDATE, 'ww')` |
| `mm` | 本年第几月 | `TO_CHAR(SYSDATE, 'mm')` |
| `q` | 本年第几季度 | `TO_CHAR(SYSDATE, 'q')` |
| `yyyy` | 年份 | `TO_CHAR(SYSDATE, 'yyyy')` |
| `month` | 月份名称 | `TO_CHAR(SYSDATE, 'month')` |
| `day` | 星期名称 | `TO_CHAR(SYSDATE, 'day')` |

## 四、字符型函数

### 4.1 concat — 连接函数

```sql
CONCAT(字符1, 字符2)
```

| 项目     | 说明                       |
| ------ | ------------------------ |
| **作用** | 将字符1和字符2拼接成一个字符，等价于 \|\| |
| **返回** | 字符                       |

---

### 4.2 大小写转换函数

| 函数 | 作用 | 返回 |
|------|------|------|
| `UPPER(字符)` | 所有字符变大写 | 字符 |
| `LOWER(字符)` | 所有字符变小写 | 字符 |
| `INITCAP(字符)` | 首字母大写，其余小写 | 字符 |

---

### 4.3 instr — 获取位置函数

```sql
INSTR(目标字符, 要查询的字符S, [位置参数n1], [次数参数n2])
```

| 项目 | 说明 |
|------|------|
| **作用** | 从第 n1 个位置开始，找到第 n2 次出现的字符 S，返回该字符在整个字符串中的位置 |
| **返回** | 数值 |
| **注意** | 空格也占位；位置可以为负（从后往前找）；次数不能为负 |

---

### 4.4 length — 获取字符长度

```sql
LENGTH(字符)
```

| 项目 | 说明 |
|------|------|
| **作用** | 获取字符的长度 |
| **返回** | 数值 |

---

### 4.5 左右删除函数

| 函数 | 作用 | 默认行为 |
|------|------|----------|
| `LTRIM(目标字符, [要删除的内容])` | 删除字符串**左侧**指定内容 | 默认删除左侧空格 |
| `RTRIM(目标字符, [要删除的内容])` | 删除字符串**右侧**指定内容 | 默认删除右侧空格 |
| `TRIM([要删除的字符 FROM] 目标字符)` | 删除字符串**左右两侧**指定内容 | 默认删除左右空格 |

---

### 4.6 replace — 替换函数

```sql
REPLACE(目标字符, 要替换的字符, 替换成的字符)
```

| 项目 | 说明 |
|------|------|
| **作用** | 将目标字符中某个或某些字符替换成想要的字符 |
| **返回** | 字符 |

---

### 4.7 substr — 截取函数

```sql
SUBSTR(目标字符, 位置参数n1, 长度参数L1)
```

| 项目 | 说明 |
|------|------|
| **作用** | 从第 n1 个位置截取出 L1 个长度的字符串 |
| **返回** | 字符 |
| **注意** | 长度默认截取到最后；位置参数必须有，可为负数（从后往前数）；截取永远从左往右；长度不能为负 |

| **返回** | 数值 |

## 六、日期型函数

### 6.1 sysdate — 获取当前日期

```sql
SELECT SYSDATE FROM dual;  -- 无参数
```

---

### 6.2 last_day — 获取月末日期

```sql
LAST_DAY(日期)
```

| 项目 | 说明 |
|------|------|
| **作用** | 返回日期所在月份的最后一天 |
| **返回** | 日期 |

---

### 6.3 months_between — 获取月份差值

```sql
MONTHS_BETWEEN(日期1, 日期2)
```

| 项目 | 说明 |
|------|------|
| **作用** | 返回两个日期之间相差的月份数 |
| **返回** | 数值 |

---

### 6.4 add_months — 月份加减

```sql
ADD_MONTHS(日期, n)
```

| 项目 | 说明 |
|------|------|
| **作用** | 在原有日期基础上加 n 个月（n 为负则减） |
| **返回** | 日期 |

---

### 6.5 round — 四舍五入后的期间第一天（日期）

```sql
ROUND(d1, [c1])
```

| 项目        | 说明                         |
| --------- | -------------------------- |
| **功能**    | 给出日期 d1 按期间 c1 四舍五入后的期间第一天 |
| **c1 默认** | `j`（最近 0 点日期）              |

**c1 参数表：**

| c1 值 | 含义 |
|-------|------|
| 取消参数 / `j` | 最近 0 点日期 |
| `day` / `dy` / `d` | 最近的星期日 |
| `month` / `mon` / `mm` / `rm` | 最近月初日期 |
| `q` | 最近季日期 |
| `syear` / `year` / `yyyy` / `yyy` / `yy` / `y` | 最近年初日期 |
| `cc` / `scc` | 最近世纪初日期 |

---

### 6.6 trunc — 截断函数（日期）

```sql
TRUNC(d1, [c1])
```

| 项目 | 说明 |
|------|------|
| **功能** | 返回日期 d1 所在期间 c1 的第一天 |
| **c1 默认** | `j`（当前日期） |

**c1 参数表同 round。** 每周顺序：日、一、二、三、四、五、六。

---

### 6.7 日期运算规则

| 运算 | 结果类型 | 示例 |
|------|----------|------|
| 日期 - 日期 | **天数** | `DATE1 - DATE2` → 数值 |
| 日期 ± 天数 | **日期** | `DATE1 + 30` → 日期 |

## 九、其他函数

### 9.1 nvl — 空值替换函数

```sql
NVL(列名, 值)
```

| 项目 | 说明 |
|------|------|
| **作用** | 将该列的空值（NULL）替换成指定的值 |
| **注意** | 替换值的类型必须和列的属性一致 |

---

### 9.2 distinct — 去重函数

```sql
SELECT DISTINCT 列名 FROM 表名;
```

| 项目 | 说明 |
|------|------|
| **作用** | 对查询结果去除重复行 |
| **无参数** | 直接使用 |
| **注意** | `DISTINCT` 效率低，`GROUP BY` 效率高 |

---

### 9.3 decode — 条件判断取值函数

```sql
DECODE(判断目标,
       判断目标返回的值1, 重新定义值1,
       判断目标返回的值2, 重新定义值2,
       判断目标返回的值3, 重新定义值3,
       ...
       [, 其他情况统一定义为值n])
```

---

### 9.4 case when — 条件判断取值

```sql
CASE
  WHEN 条件1 THEN 结果1        -- 满足条件1执行的结果
  WHEN 条件2 THEN 结果2
  WHEN 条件3 THEN 结果3
  ...
  [ELSE 其他结果]              -- 没有满足以上所有条件时执行的结果
END
```

> 条件中可使用 `AND`、`OR` 组合多个条件。
