### (3)排序查询
定义：对查询结果按照一定规则升序或者降序
语法：
```
select
  from
    where
      order by 排序内容  asc | desc ;-----asc可以不写，默认就是升序
```
注： 空值最大
```
select
  from emp
    order by sal desc nulls last;----让空值最后，还有就是nulls first 让空值最前。
```
例题  查询 emp 表员工信息-按照部门升序排列，每个部门里面在按照工资降序排列
```
select
  from emp
    order by deptno asc,sal desc;
注：orderby 后面能放多个列，先按第一列排序然后再按第二列排序.....
```
> [!note]+
> 例题  查询工资大于1000的员工的信息结果按照部门升序工资降序
> ```
> select *  ---------------------------------3 ---结果
>   from emp   -------------------------------1
>      where sal > 1000  --------------------2
>          order by deptno asc, sal desc  ---4
> ```
> ```
> select ename e, sal s 
>   from emp
>     where s > 1000--------(cuo)where后面不能用别名
>       order by deptno s desc;  -----order by 后面能用别名字
> ```

### （4)分组查询
定义：按照一定规则分组，统一分析各组的情况，每一组返回一个值
语法：
```
SELECT 列名, 聚合函数()
  FROM 表名
     WHERE 行过滤条件 -------------分组前的过滤条件
      GROUP BY 分组字段------------分组内容
         HAVING  -----------------分组后过滤条件
     ORDER BY 排序字段;
```
分组函数------聚合函数------聚组函数
sum ()------求和
avg ()-------求平均
min ()------最小值
max()-------最大值
count()------计数
> [!abstract]+
> 例题  查询emp表中所有员工的薪资总和
> ```
> select sum(sal) from emp; --19688
> select sum(sal) /12,avg(sal), min(sal),max(sal) from emp;
> ```
> 注意:空值不参与聚合函数的统计
> ```
> select ename, deptno, avg(sal)
>    from emp
>      group by deptno;
> ```
> 注意：使用分组查询时 select 后面只能展示 group by 后面有的字段
> 例题  查询每个部门的每个岗位的平均工资
> ```
> select deptno, job, avg(sal)
>   from emp
>      group by deptno, job
> ```
> 注意：group by 后面也可以跟多个字段 先按第一列分组，然后再按照第二列分组
> ```
> select deptno,job,avg(sal)
>   from emp
>     where sal>1000———------分组前的条件--—不能使用聚合函数的条件
>   group by deptno，job
>     having avg(sal)>2000-—-分组后的条件--—能使用聚合函数的条件
> ```
